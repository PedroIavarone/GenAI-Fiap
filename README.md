## 📌 About

This project is an **AI Super App** built with a [Gradio](https://www.gradio.app/) interface, running directly on Google Colab. It integrates **eight AI features** using exclusively **open-source** models from [Hugging Face](https://huggingface.co/), with no reliance on paid external APIs — all processing runs locally on the host machine.

Developed as Checkpoint 1 for the **Artificial Intelligence** course at [FIAP](https://www.fiap.com.br/), under the guidance of Professor Erick Gomes.

## 🧠 Technical Details

### 1. 🖼️ Image Classification — Vision Transformer (ViT)

- **Architecture:** ViT applies the *Attention* mechanism from Transformers (originally from NLP) directly to pixel blocks (*patches*) of the image, outperforming traditional CNNs on many tasks.
- **Training dataset:** ImageNet (1,000 predefined classes).
- **Limitations:** Restricted to ImageNet categories; labels are in English only.
- **Use cases:** Photo gallery organization, product pre-classification in e-commerce.

### 2. 🎙️ Audio Transcription — Whisper (OpenAI)

- **Architecture:** Encoder-decoder model trained on 680,000 hours of multilingual audio. Extremely robust against background noise and accents.
- **Version:** `whisper-tiny` — optimized for low RAM/VRAM consumption, ideal for Colab.
- **Limitations:** Lower accuracy than larger versions for highly technical or very long audio.
- **Use cases:** Automatic subtitles for videos, meeting transcription, voice message to text.

### 3. 📝 Image Captioning — BLIP (Salesforce)

- **Architecture:** BLIP (*Bootstrapping Language-Image Pre-training*) unifies computer vision and NLP to generate descriptive text from images.
- **Differentiator:** Unlike classification, it understands the **scene context** and generates a full sentence.
- **Limitations:** Captions are generated in English only; may be overly literal with artistic or subjective content.
- **Use cases:** Automatic `alt text` generation for web accessibility, social media caption suggestions.

## 🚀 How to Run

### ▶️ Option 1: Google Colab (Recommended)

1. Click the badge below to open directly in Colab:

   [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/15__SOYpNshD5716OW5ehAJ7IXbHWC2N1?usp=sharing)

2. Run all cells in order (`Runtime → Run all`)
3. Wait for models to load (~3–5 minutes)
4. Access the public URL generated by Gradio (`share=True`)

### 💻 Option 2: Locally

```bash
# Clone the repository
git clone https://github.com/PedroIavarone/GenAI-Fiap
cd GenAI-Fiap

# Install dependencies
pip install gradio transformers torch torchvision torchaudio soundfile

# Run the notebook
jupyter notebook notebook/CP1_GenAI_SUPER_APP_DE_GENAI.ipynb
```

> ⚠️ **Local requirements:** Python 3.10+, ~4GB of free RAM to load all models.
